# Estándares de California — lista de validación

Estado general: **BORRADOR. Ningún docente ha validado esto.** No publicar contenido por grado hasta que cada fila esté en «Validado».

Cómo usar: un docente de California revisa cada fila contra el documento oficial, corrige el código o la redacción, y firma. Nada de lo que está aquí debe presentarse a las familias como «alineado» hasta entonces.

Fuentes oficiales a consultar: CA Common Core State Standards (Matemáticas y ELA/Literacy), California NGSS (Ciencia), California History–Social Science Framework y Standards, California Arts Standards (VAPA), y el CA ELD Framework.

## Antes de publicar, el docente debe confirmar
1. El código y su redacción correspondiente al grado.
2. Que la actividad realmente evalúa o practica ese estándar (no solo el tema).
3. Vocabulario y ejemplos apropiados para el grado.
4. Que el informe para la maestra (P5) cita el código correcto.

## Cómo se muestra en la app
- El código aparece solo en la vista de padres (P2, P3, P5), nunca al niño.
- Mientras una unidad esté «Por validar», el informe la marca con «borrador» en lugar de mostrar el código.
