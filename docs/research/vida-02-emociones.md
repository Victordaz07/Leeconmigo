# KiteWise · Módulo 02: Emociones y autorregulación

**Manual de aprendizaje de 1.º a 6.º de primaria**  
**Edición:** 16 de octubre de 2026.  
**Incluye:** 48 lecciones desarrolladas, 12 talleres prácticos, seis proyectos, evaluación con respuestas orientativas, guiones de acompañamiento y propuestas de experiencias interactivas.  
**Idioma desarrollado:** español; glosario español–inglés. La traducción íntegra requiere una fase editorial posterior.

## 1. Para qué sirve este módulo

Sentir alegría, tristeza, enojo, miedo, vergüenza o una mezcla de emociones forma parte de la vida. Aquí aprenderás a observar lo que te pasa, encontrar palabras o dibujos para expresarlo, reconocer necesidades y elegir acciones que cuiden de ti y de los demás. No tendrás que estar feliz para avanzar.

**Autorregularse** significa aprender a reconocer y ajustar nuestras respuestas con los apoyos necesarios. No significa dejar de sentir ni hacerlo todo a solas. **Corregularse** significa recibir apoyo de una persona que ayuda a atravesar un momento difícil. Pedir compañía, reducir ruido o cambiar una instrucción puede ser tan importante como practicar una herramienta personal.

Trabajaremos con personajes y situaciones inventadas. Puedes usar una experiencia propia si quieres, pero también puedes decir «prefiero trabajar con el personaje», «no lo sé todavía» o «paso esta pregunta». No tienes que contar algo privado para demostrar que aprendiste.

**Alcance:** es un programa educativo propuesto, no una evaluación clínica ni un tratamiento. Las lecciones y soluciones están escritas para estudiar; las experiencias digitales descritas todavía requieren implementación. La graduación por curso es una propuesta original de KiteWise y debe ajustarse a las necesidades del grupo.

### Acuerdos para aprender

1. Podemos hablar de cualquier emoción sin llamarla mala ni burlarnos de quien la siente.
2. Todas las emociones pueden reconocerse; las acciones tienen límites: no lastimar, amenazar ni humillar.
3. Nadie tiene que mostrar una cara, cerrar los ojos, respirar de una forma o aceptar contacto físico para participar.
4. Una cara o una conducta puede dar pistas, pero no permite saber con certeza lo que alguien siente.
5. La seguridad y el apoyo van primero. Practicar calma no sustituye detener una agresión ni cambiar una situación dañina.
6. Si hay peligro o alguien hace daño, se busca ayuda adulta. No es responsabilidad del niño resolverlo solo.

## 2. Investigación y decisiones curriculares

El marco de CASEL organiza el aprendizaje socioemocional en autoconocimiento, autogestión, conciencia social, habilidades de relación y decisiones responsables. Este módulo se centra en las dos primeras y establece puentes con las demás; el siguiente módulo, Comunicación y convivencia, profundizará en habilidades interpersonales. No se presenta KiteWise como un programa avalado por CASEL. [R1]

Los recursos de la American Academy of Pediatrics sobre estrés infantil destacan el papel del adulto y la conexión antes de exigir una conversación compleja. Aquí esto se traduce en asegurar protección, ofrecer apoyo y después analizar alternativas. La secuencia concreta y los guiones de KiteWise son originales. [R2]

UNICEF recomienda una escucha que permita al niño expresarse y participar en la respuesta. NHS reconoce también la utilidad de otras personas de confianza y de respetar el momento en que un niño está preparado para hablar. Por eso se admiten silencio, dibujo, comunicación aumentativa y ejemplos ficticios. [R3–R4]

El juego y la creación se incorporan como vías de expresión, inspiradas en los recursos educativos de UNICEF. Una producción artística no se interpreta como diagnóstico ni se utiliza para deducir automáticamente experiencias ocultas. [R5]

### Principios que guían el contenido

| Principio | Cómo se aplica |
|---|---|
| Reconocer sin imponer | El estudiante puede nombrar otra emoción o decir que aún no sabe |
| Contexto y acceso | Se revisan ruido, instrucciones, hambre, descanso, trato y apoyos disponibles |
| Elección de herramientas | Se ofrecen varias opciones; una misma estrategia no funciona para todos |
| Práctica gradual | Se ensayan situaciones pequeñas y ficticias cuando hay disposición |
| Responsabilidad adulta | El adulto protege, adapta y acompaña; no exige al niño regular el ambiente familiar |
| Privacidad | No se obliga a revelar vivencias, registrar estados diarios ni compartir un diario |
| Aprendizaje observable | Se evalúan explicaciones y decisiones de casos, no sentimientos personales |
| Reparación | Reconocer el impacto de una acción no exige aceptar una identidad negativa |

No son edades rígidas ni una escala de madurez. Un estudiante de cualquier grado puede necesitar herramientas visuales, corregulación o una explicación más concreta. Pedir más apoyo no implica retroceder.

## 3. Cómo trabajar las lecciones

Cada lección incluye una meta, explicación para el estudiante, caso resuelto, práctica, respuestas orientativas y actividad para KiteWise. Como punto de partida de planificación, usar encuentros de 15–25 minutos y proyectos divididos en varios momentos; no es una duración validada. En los primeros grados se recomienda lectura acompañada, títeres y dibujos.

**Secuencia sugerida:** presentar un personaje → leer o escuchar → modelar una opción → permitir elegir o pasar → practicar con el personaje → revisar qué aprendimos. No abrir una conversación íntima ante todo el grupo como requisito de entrada.

**Qué es una respuesta orientativa:** en una suma suele haber un resultado definido. En una situación emocional puede haber varias respuestas razonables. Las soluciones indican conceptos y acciones posibles; no afirman cuál tendría que ser tu emoción. Si el caso dice «Lina cuenta que está triste», se respeta lo que ella expresa.

**Ruta práctica original P-A-R:** **P**roteger y pedir apoyo; **A**tender señales y elegir una opción; **R**evisar después. Es una ayuda de memoria de KiteWise, no una técnica clínica validada ni un protocolo que deba completarse en orden durante una emergencia.

## 4. Primer grado · Reconozco y pido ayuda

### E1.1 · Las emociones tienen nombres

**Meta:** identificar palabras iniciales sin clasificar a las personas como buenas o malas.

**Aprende:** una emoción es parte de lo que sientes ante lo que ocurre, recuerdas o imaginas. Podemos decir alegría, tristeza, miedo, enojo, sorpresa o calma. No siempre encontramos el nombre enseguida. Puedes decir «algo me pasa» y pedir ayuda.

**Caso resuelto:** a Teo se le rompe una construcción. Dice: «Estoy triste y enojado». No tiene que elegir solo una palabra. Una compañera responde: «¿Quieres ayuda o compañía?».

**Practica:** a) ¿Teo puede sentir dos emociones? b) ¿Qué podría decir alguien que todavía no sabe nombrar lo que siente?

**Respuestas orientativas:** a) Sí. b) «No sé cómo explicarlo», señalar una tarjeta o mostrar un dibujo. No se exige adivinar por su cara.

**En KiteWise:** biblioteca de palabras con narración y escenas. Elegir «otra», «mezcla» o «no sé» siempre es posible.

### E1.2 · Mi cuerpo puede dar pistas

**Meta:** observar una señal sin convertirla en una certeza.

**Aprende:** a veces notas manos apretadas, ganas de moverte, lágrimas o un nudo en la barriga. Son pistas, no un código igual para todos. Una misma sensación puede tener causas distintas. No tienes que mirar dentro de tu cuerpo si eso te incomoda.

**Caso resuelto:** Sara nota la barriga rara antes de una actividad. Podría estar nerviosa, tener hambre o sentirse mal. Le dice a una adulta lo que nota; la adulta escucha en vez de decidir de inmediato.

**Practica:** a) ¿«Me duele la barriga» prueba que alguien tiene miedo? b) ¿A quién puede contarlo si le preocupa?

**Respuestas:** a) No; no se diagnostica una emoción a partir de una señal. b) A una persona adulta de confianza. Un dolor necesita atención apropiada; no se etiqueta automáticamente como emocional.

**En KiteWise:** silueta opcional o alternativa de elegir palabras sobre un personaje; sin cámara ni sensores.

### E1.3 · Sentir y hacer son diferentes

**Meta:** distinguir una emoción de una acción.

**Aprende:** puedes sentir enojo y aun así necesitar ayuda para no lastimar. El sentimiento no te hace malo. Empujar, romper o insultar puede causar daño; hay otras maneras de expresar que algo no está bien.

**Caso resuelto:** a Bruno le quitan un lápiz y siente enojo. Puede decir «lo estaba usando», alejar las manos del compañero y pedir apoyo. El adulto también debe ayudar a recuperar el material.

**Practica:** a) En «siento enojo y pateo una silla», ¿qué es emoción y qué es acción? b) Propón otra acción.

**Respuestas:** a) Enojo es emoción; patear es acción. b) Avisar, tomar distancia segura o pedir que se respete el turno. No se exige aguantar que le quiten sus cosas.

**En KiteWise:** dos zonas llamadas «lo que siente» y «lo que hace», con etiquetas escritas y audio.

### E1.4 · Una pausa con compañía

**Meta:** reconocer una pausa como apoyo, no como castigo.

**Aprende:** a veces puedes detener una actividad para recibir ayuda. Una pausa puede ser sentarte cerca de alguien, bajar el sonido o mirar un objeto tranquilo. No necesitas dejar de llorar para que te acompañen.

**Caso resuelto:** el salón está ruidoso y Nia se tapa los oídos. La maestra ofrece un lugar menos ruidoso y dice: «Puedo quedarme cerca». No la manda sola a «portarse bien».

**Practica:** a) ¿La pausa significa que Nia es mala? b) ¿Qué opción puede elegir si no quiere hablar?

**Respuestas:** a) No. b) Señalar un lugar, usar una tarjeta o aceptar compañía en silencio. La pausa no tiene que durar un número fijo de minutos.

**En KiteWise:** botón «quiero una pausa» que abre opciones simples y permite salir. No bloquea el regreso hasta que el niño seleccione «feliz».

### E1.5 · Puedo expresar lo que necesito

**Meta:** practicar una petición concreta y accesible.

**Aprende:** una necesidad puede expresarse con palabras, gestos, dibujos o un dispositivo de comunicación. Puedes pedir agua, menos ruido, una explicación, espacio o compañía. Que no puedas hablar en ese momento no significa que no tengas nada que comunicar.

**Caso resuelto:** Lina no entiende una consigna. Señala una tarjeta: «Muéstrame un ejemplo». La maestra divide la tarea y enseña el primer paso.

**Practica:** a) Completa para un personaje: «Necesito ayuda con ___». b) ¿Tiene que pedirlo con voz fuerte y mirando a los ojos?

**Respuestas:** a) Se acepta una necesidad clara del caso. b) No. La petición puede hacerse de varias formas y sin contacto visual.

**En KiteWise:** constructor de peticiones con iconos y audio opcional. La actividad prepara una conversación; no afirma que envió un mensaje a un adulto.

### E1.6 · No todos sentimos lo mismo

**Meta:** aceptar diferencias sin adivinar ni corregir sentimientos.

**Aprende:** ante una misma actividad, una persona puede estar emocionada y otra preocupada. Preguntar ayuda más que decidir por ella. También podemos necesitar apoyos distintos.

**Caso resuelto:** una clase prepara una presentación. Teo quiere actuar; Mara prefiere mover los títeres. Mara dice que le gusta participar sin estar frente al grupo. Ambas formas pueden aportar.

**Practica:** a) ¿Todos tienen que entusiasmarse igual? b) ¿Qué pregunta respetuosa puedes hacer?

**Respuestas:** a) No. b) «¿Cómo te gustaría participar?» o «¿Quieres contarme cómo te sientes?». También se respeta «no quiero hablar ahora».

**En KiteWise:** la misma escena muestra distintos relatos de sus personajes. La sonrisa dibujada no determina la respuesta correcta.

### E1.7 · Mi red de personas de confianza

**Meta:** reconocer más de una vía de apoyo.

**Aprende:** una persona de confianza escucha, cuida y busca ayuda cuando hace falta. Puede ser alguien del hogar, de la escuela u otro adulto conocido. Si la primera persona no ayuda, puedes buscar a otra. No tienes que resolver solo una situación que te asusta o lastima.

**Caso resuelto:** un niño necesita ayuda en el recreo y su maestra está ocupada. Acude a otra persona del equipo escolar que tiene asignada esa función.

**Practica:** a) ¿Hay una sola persona posible? b) ¿Qué puedes hacer si te dicen que no es importante y sigues necesitando ayuda?

**Respuestas:** a) No. b) Contarlo a otro adulto de confianza. La falta de respuesta no vuelve inválida la necesidad.

**En KiteWise:** construir una red con roles o personajes ficticios. No pedir nombres completos, teléfonos ni direcciones.

### E1.8 · Proyecto: mi tarjeta de apoyo

**Meta:** reunir palabras, una opción y una forma de pedir compañía.

**Aprende:** una tarjeta puede ayudarte a comunicar cuando hablar resulta difícil. No tiene que explicar todo lo ocurrido: basta con indicar que necesitas apoyo. Su utilidad depende también de que una persona la atienda.

**Caso:** un personaje llega a una actividad nueva y dice que se siente inseguro. Diseña una tarjeta que pueda llevar a un adulto.

**Ejemplo resuelto:** «Algo me cuesta. Puedo señalar esta tarjeta. Me ayuda que me enseñes dónde empezar. Si no puedes, ayúdame a encontrar a otra persona». Puede acompañarse de un dibujo.

**Practica:** a) ¿La tarjeta tiene que borrar el miedo? b) ¿Puede usarla alguien que no lee todavía?

**Respuestas:** a) No; su función es facilitar apoyo. b) Sí, con iconos, gestos y modelado de un adulto.

**Entrega:** una tarjeta para el personaje y una demostración con títeres. El estudiante decide si quiere una versión personal.

**En KiteWise:** editor de tarjetas con opción de imprimir y sin publicación automática.

**Transferencia opcional de 1.º:** representar con un muñeco cómo pedir ayuda cuando una tarea no se entiende. No se pide contar un momento difícil real.

## 5. Segundo grado · Intensidad y herramientas

### E2.1 · Una emoción puede sentirse pequeña o grande

**Meta:** describir intensidad sin competir.

**Aprende:** una emoción puede sentirse suave, media o muy intensa. Las palabras o escalas ayudan a comunicar cómo la vive cada persona; no permiten compararla con la de otro. No existe una nota por sentir poco.

**Caso resuelto:** Alex dice que su enojo es «grande» porque no logra explicar lo ocurrido. Bea describe un enojo «pequeño». No podemos concluir que uno exagera.

**Practica:** a) ¿«Grande» significa lo mismo para todos? b) ¿Puede alguien necesitar ayuda aunque marque intensidad baja?

**Respuestas:** a) No. b) Sí. Una herramienta de comunicación no decide si merece apoyo. Puede preferirse una palabra a un número.

**En KiteWise:** medidor opcional con palabras, sin rojo malo/verde bueno, sin promedio de «mejor ánimo» y con opción «no sé».

### E2.2 · Notar antes de actuar

**Meta:** reconocer una señal inicial en una historia.

**Aprende:** a veces notar una señal pronto permite pedir apoyo antes de que la situación sea más difícil. Otras veces la emoción aparece rápido y no la notas; no es una falta moral.

**Caso resuelto:** al perder varias rondas, Teo aprieta las piezas y piensa en lanzarlas. Puede dejar las piezas sobre la mesa y pedir una pausa acompañada. La persona adulta retira objetos peligrosos si fuera necesario.

**Practica:** a) ¿Cuál era la señal del caso? b) ¿Qué puede hacerse si ya lanzó una pieza?

**Respuestas:** a) Apretar las piezas y notar el impulso. b) Primero asegurar que nadie esté en peligro; después, con apoyo, revisar y reparar. No se exige analizar todo mientras está desbordado.

**En KiteWise:** línea de escenas con momentos posibles para pedir ayuda; no castigar por «haber llegado tarde».

### E2.3 · Respirar suave es una opción

**Meta:** explorar una herramienta sin obligación ni promesas.

**Aprende:** a algunas personas les ayuda prestar atención a una respiración suave. A otras no les resulta cómodo. Puedes mantener los ojos abiertos y respirar a tu ritmo. No hay que aguantar el aire, respirar muy hondo ni competir.

**Práctica guiada:** si quieres, observa una figura que se ensancha y se estrecha. Acompaña una o dos respiraciones cómodas. Después elige continuar, parar o cambiar a mirar un objeto. Si hay mareo, incomodidad o dificultad para respirar, detén el ejercicio y avisa a un adulto; una dificultad física necesita atención adecuada.

**Practica:** a) ¿Es obligatorio respirar con la figura? b) ¿Qué puedes hacer si no te ayuda?

**Respuestas:** a) No. b) Parar y elegir otra opción o pedir compañía. Ningún resultado indica éxito o fracaso emocional.

**En KiteWise:** animación opcional, sin micrófono, medición respiratoria ni retenciones; control visible para salir.

### E2.4 · Movimiento y entorno

**Meta:** proponer ajustes que respeten el cuerpo y el espacio.

**Aprende:** una pausa puede incluir estirarte cómodamente, cambiar de postura o caminar con permiso en un lugar seguro. También puedes necesitar menos luz, menos ruido o una instrucción diferente. No todo se soluciona quedándote quieto.

**Caso resuelto:** en una actividad larga, Mara necesita moverse. Acuerda hacer una parte de pie y otra sentada. La tarea conserva su objetivo y cambia la forma de participar.

**Practica:** a) ¿Moverse siempre significa desobedecer? b) Propón una alternativa para quien no puede caminar o no quiere estirarse.

**Respuestas:** a) No. b) Cambiar de posición si resulta cómodo, usar un apoyo, descansar o ajustar el entorno. No se impone una capacidad física como requisito de calma.

**En KiteWise:** seleccionar entre opciones equivalentes, incluida «prefiero no hacer movimiento».

### E2.5 · Cuando algo no sale

**Meta:** reconocer frustración y modificar un intento.

**Aprende:** la frustración puede aparecer cuando quieres lograr algo y encuentras una dificultad. Puedes descansar, pedir un ejemplo, dividir la tarea o probar otra herramienta. Esforzarte no significa repetir indefinidamente algo que no funciona.

**Caso resuelto:** una torre se cae tres veces. Nia puede probar una base más ancha, construir con ayuda o dejarlo para después. No necesita decir que le gusta que se caiga.

**Practica:** a) ¿Qué cambia si usa una base más ancha? b) ¿Pedir ayuda elimina su participación?

**Respuestas:** a) La estrategia, no solo la cantidad de intentos. b) No; aprender también incluye usar apoyos. Puede seguir decepcionada y estar aprendiendo.

**En KiteWise:** construcción manipulable con materiales virtuales; ofrecer pistas y pausa sin quitar puntos por utilizarlas.

### E2.6 · Esperar con un plan

**Meta:** preparar un apoyo para una espera comprensible.

**Aprende:** esperar suele resultar más fácil si sabes qué ocurrirá, cuándo será tu turno o qué puedes hacer mientras. Una espera indefinida necesita aclaración. Pedir agua, ir al baño o comunicar dolor no debe tratarse como un ejercicio de aguante.

**Caso resuelto:** tres niños esperan un material. El adulto muestra el orden y ofrece otra tarea. Si cambia el tiempo, avisa en vez de repetir «ya casi» sin información.

**Practica:** a) ¿Qué puede preguntar el personaje? b) ¿Es obligatorio soportar una necesidad física para demostrar paciencia?

**Respuestas:** a) «¿Quién va antes?» o «¿Qué puedo hacer mientras?». b) No; debe comunicarla y recibir ayuda.

**En KiteWise:** cola visual de personajes con cambios anunciados; sin cuenta regresiva que provoque presión.

### E2.7 · Cambiar de actividad

**Meta:** construir una transición con aviso y próximo paso.

**Aprende:** terminar algo entretenido puede dar tristeza, enojo o ganas de seguir. Un aviso y un lugar donde guardar ayudan a saber que habrá continuidad. A veces el adulto necesita explicar un cambio inesperado.

**Caso resuelto:** se acerca el final de un dibujo. La maestra avisa, permite guardar una foto del avance y muestra qué viene después. El niño puede decir «quiero continuar mañana».

**Practica:** a) ¿Qué dos apoyos aparecen? b) Si hay que salir de inmediato por seguridad, ¿se espera a terminar el dibujo?

**Respuestas:** a) Aviso, guardado y explicación de la siguiente actividad; bastan dos. b) No; primero se protege y después se explica y acompaña la interrupción.

**En KiteWise:** guardar automáticamente y mostrar «puedes retomarlo». No borrar una creación por salir antes.

### E2.8 · Proyecto: mi caja de opciones

**Meta:** combinar herramientas personales, cambios del entorno y ayuda adulta.

**Aprende:** una caja de opciones es un menú, no una lista de obligaciones. Puede incluir herramientas que pruebas por tu cuenta y apoyos que otras personas deben facilitar. Puedes cambiarla cuando tus necesidades cambien.

**Caso:** un personaje se frustra con un rompecabezas en un lugar ruidoso. Prepara tres tarjetas que ofrezcan apoyos diferentes.

**Ejemplo resuelto:** «Moverme a un lugar menos ruidoso», «Pedir que me muestren una pieza» y «Hacer una pausa con alguien». La respiración podría ser otra opción, pero no sustituye reducir el ruido.

**Practica:** a) ¿Tiene que usar todas las tarjetas? b) ¿Qué hace si ninguna ayuda?

**Respuestas:** a) No; puede elegir una, combinar o cambiar. b) Pedir más apoyo y revisar la tarea o el entorno. No significa que haya fallado.

**Entrega:** tres tarjetas para el personaje, explicación de cuándo podrían servir y una tarjeta «necesito otra ayuda».

**En KiteWise:** caja editable; el estudiante puede retirar herramientas que no le sirven.

**Transferencia opcional de 2.º:** prepara una transición para un juego ficticio: aviso, guardado y siguiente actividad. Ensáyala con muñecos.

## 6. Tercer grado · Situaciones, ideas y respuestas

### E3.1 · Hecho, pensamiento y emoción

**Meta:** diferenciar tres elementos de una situación.

**Aprende:** un hecho es algo que ocurrió y puede describirse. Un pensamiento es una idea o interpretación. Una emoción es parte de cómo vives la situación. Se relacionan, pero no son lo mismo. No todo malestar nace de pensar «incorrectamente»; también importan condiciones reales.

**Caso resuelto:** «La respuesta a mi mensaje no ha llegado» es un hecho del caso. «Ya no quiere ser mi amiga» es una interpretación. «Me siento triste» nombra una emoción. Puede faltar información para saber por qué no respondió.

**Practica:** a) Clasifica «se canceló el juego», «nunca podré jugar» y «siento decepción». b) ¿La decepción debe desaparecer para preguntar por otra fecha?

**Respuestas:** a) Hecho, pensamiento y emoción, respectivamente. b) No; se puede actuar con apoyo mientras una emoción continúa.

**En KiteWise:** clasificar tarjetas y aceptar que una frase compleja contenga más de un elemento, explicando cómo separarla.

### E3.2 · Intensidad y necesidad de apoyo

**Meta:** utilizar una escala como comunicación, no como diagnóstico.

**Aprende:** puedes elegir palabras o una escala personal de 1 a 5 para comunicar intensidad. No es una medición exacta ni una comparación entre personas. A veces ayuda indicar además si puedes continuar o necesitas apoyo.

**Caso resuelto:** Diego marca «4, necesito compañía» antes de una presentación. Después del apoyo marca «4, puedo ensayar con alguien». El número no bajó, pero cambió lo que puede hacer con ayuda.

**Practica:** a) ¿Significa que el apoyo fracasó? b) ¿Debe marcar 1 para volver a aprender?

**Respuestas:** a) No. b) No. Se considera disposición, seguridad y apoyos, sin exigir una emoción específica.

**En KiteWise:** dos campos opcionales: «cómo lo describo» y «qué apoyo quiero». No calcular un puntaje de salud mental a partir de ellos.

### E3.3 · Desencadenantes y contexto

**Meta:** reconocer condiciones que pueden contribuir a una respuesta.

**Aprende:** un desencadenante es algo que puede iniciar o intensificar una reacción en una persona. No actúa igual para todos. Ruido, cambios inesperados o una experiencia anterior pueden influir. Encontrar una causa posible no justifica hacer daño ni permite culpar al niño.

**Caso resuelto:** a un personaje le cuesta una tarea después de varias instrucciones rápidas. Se prueba una instrucción por vez y un ejemplo visual. No se concluye que «no quiere trabajar».

**Practica:** a) ¿Qué condición podría cambiar el adulto? b) ¿Necesita el niño demostrar una causa exacta para pedir ayuda?

**Respuestas:** a) Ritmo, cantidad de instrucciones o forma de presentarlas. b) No. Puede pedir apoyo aunque todavía no comprenda lo que ocurre.

**En KiteWise:** escena con controles de contexto, no una lista de «personas que me provocan».

### E3.4 · Impulso y elección apoyada

**Meta:** reconocer que un impulso no es una orden.

**Aprende:** un impulso son ganas de actuar rápidamente. Puede ser responder, gritar o salir corriendo. En situaciones de práctica puedes ensayar una pausa, alejar un objeto o pedir que alguien te ayude a decidir. En peligro real se busca seguridad; no se exige quedarse pensando.

**Caso resuelto:** Leo quiere enviar un mensaje hiriente tras perder un juego. Lo deja como borrador, se aparta de la pantalla y pide ayuda. Su enojo no se vuelve inválido por no enviarlo.

**Practica:** a) ¿Sentir ganas de escribirlo equivale a haberlo enviado? b) Propón una respuesta distinta.

**Respuestas:** a) No. b) Esperar con apoyo, explicar que necesita salir del juego o pedir revisión de una conducta injusta. «No responder» puede ser adecuado, sin resolver por sí solo el problema.

**En KiteWise:** borrador ficticio con caminos alternativos; sin publicación externa.

### E3.5 · Otras explicaciones posibles

**Meta:** proponer alternativas sin negar hechos ni riesgos.

**Aprende:** cuando falta información, puedes pensar en más de una explicación. Eso no significa obligarte a creer que todo está bien. Una explicación debe ser posible y revisable, no una frase positiva inventada.

**Caso resuelto:** «No me saludó; quizá no me vio, estaba ocupado o estaba molesto». Hay alternativas. Si hubo un insulto claro, no se borra diciendo «seguro fue cariño».

**Practica:** a) Tu compañero no ha respondido una pregunta. Escribe dos posibilidades. b) Si te amenaza, ¿debes esperar a encontrar una explicación amable antes de pedir ayuda?

**Respuestas:** a) No escuchó, está pensando, no sabe o no quiere responder, entre otras. b) No. Una amenaza requiere apoyo y protección.

**En KiteWise:** mostrar qué se sabe, qué se supone y qué puede preguntarse de manera segura.

### E3.6 · Resolver una dificultad por pasos

**Meta:** definir un problema concreto y comparar opciones.

**Aprende:** después de recibir apoyo, puede ayudar preguntar: ¿qué pasó?, ¿qué necesito?, ¿qué opciones hay?, ¿cuál podemos probar? Un problema no es «soy un desastre»; puede ser «no entiendo el primer paso».

**Caso resuelto:** un equipo tiene un solo pincel ancho. Puede turnarse, usar otra herramienta o cambiar una parte del diseño. Empieza por identificar el recurso limitado, no por culpar.

**Practica:** a) Reformula «todo está mal» para el caso del pincel. b) Nombra dos opciones y una consecuencia posible de cada una.

**Respuestas:** a) «Necesitamos usar el mismo pincel al mismo tiempo». b) Turnarse permite compartir, pero requiere organizar la espera; otra herramienta evita esperar, pero puede cambiar el resultado. No hay una única elección obligatoria.

**En KiteWise:** construir un árbol de opciones de dos o tres ramas con consecuencias explícitas.

### E3.7 · Hablarme con respeto

**Meta:** separar un error de una etiqueta sobre la persona.

**Aprende:** una frase respetuosa puede reconocer una dificultad y sugerir un apoyo. No tienes que afirmar que eres excelente en todo. «No entiendo esto todavía y puedo pedir un ejemplo» es más concreto que «soy incapaz».

**Caso resuelto:** después de equivocarse, Ana piensa «nunca hago nada bien». Revisa el hecho: falló una parte de una actividad. Puede decir: «Esta parte me cuesta; voy a revisarla con alguien».

**Practica:** a) Cambia «soy tonto porque me equivoqué» por una descripción concreta. b) ¿Una frase nueva garantiza acertar?

**Respuestas:** a) «Me equivoqué en este paso y necesito revisarlo». b) No; permite un trato más respetuoso y puede orientar una acción. También pueden hacer falta apoyos materiales o de enseñanza.

**En KiteWise:** editor de frases sobre personajes. No detectar ni puntuar pensamientos privados.

### E3.8 · Proyecto: detective de una situación

**Meta:** integrar hechos, posibles interpretaciones, emoción expresada y apoyo.

**Aprende:** revisar información no significa dudar de todo lo que alguien cuenta. Significa distinguir lo conocido de lo supuesto y ajustar una respuesta cuando aparecen datos. Si hay daño, se atiende sin exigir que la persona afectada resuelva la investigación.

**Caso:** Sol llega a una mesa de juego. No hay una silla libre. Piensa «no me quieren aquí» y dice que está triste. El grupo todavía no ha explicado qué ocurrió.

**Ejemplo resuelto:** hecho: no hay silla. Interpretación: rechazo. Emoción expresada: tristeza. Opciones: preguntar si puede incorporarse o pedir ayuda para organizar un lugar. Si el grupo la excluye intencionalmente, un adulto debe atender esa situación; no basta cambiar su pensamiento.

**Practica:** a) ¿Sabemos por qué no hay silla? b) ¿Qué información conviene buscar?

**Respuestas:** a) No. b) Si estaba previsto su lugar, si falta mobiliario o si existe exclusión. No se exige afrontar a solas al grupo.

**Entrega:** cuatro tarjetas y dos caminos posibles según la información posterior.

**En KiteWise:** revelar detalles después de la primera interpretación y permitir revisarla sin penalización.

**Transferencia opcional de 3.º:** inventa una escena ambigua de cómic y escribe dos explicaciones posibles. No uses un conflicto real de un compañero.

## 7. Cuarto grado · Mezclas, flexibilidad y reparación

### E4.1 · Emociones que conviven

**Meta:** reconocer dos emociones simultáneas sin tratarlas como contradicción.

**Aprende:** puedes alegrarte por una oportunidad y sentir miedo de lo nuevo. Puedes extrañar a una persona y disfrutar algo ese mismo día. Una emoción no cancela automáticamente la otra.

**Caso resuelto:** Mara cambia de escuela. Dice: «Quiero conocer el taller de arte y también extraño mi salón». El adulto puede escuchar ambas partes y preparar apoyos para el cambio.

**Practica:** a) ¿Disfrutar del taller demostraría que dejó de extrañar? b) Escribe una petición que respete las dos experiencias.

**Respuestas:** a) No. b) «Quiero conocer el taller y también hablar de lo que extraño». No se obliga a encontrar dos emociones si la persona reconoce una o ninguna.

**En KiteWise:** mezclar palabras o símbolos en una composición. La mezcla no genera un diagnóstico ni una emoción matemática exacta.

### E4.2 · Enojo, tristeza y vergüenza

**Meta:** ampliar vocabulario sin imponer una jerarquía emocional.

**Aprende:** el enojo puede aparecer ante un límite o una injusticia; la tristeza, ante una pérdida; la vergüenza, al sentirnos expuestos. Son ejemplos, no reglas. A veces se mezclan. No puedes deducir que detrás de cada enojo hay otra emoción específica.

**Caso resuelto:** a un personaje se le cae un proyecto frente al grupo. Cuenta que siente vergüenza y enojo por las risas. Se protege del ridículo, se atiende la burla y se ofrece ayuda para el proyecto.

**Practica:** a) ¿Basta con decirle que no se avergüence? b) ¿Qué responsabilidad tiene el adulto?

**Respuestas:** a) No. b) Detener las burlas y ofrecer apoyo, sin exigir que explique sus sentimientos ante todos.

**En KiteWise:** las emociones se conocen por el relato del personaje, no por una lectura automática del rostro.

### E4.3 · Error, culpa y responsabilidad

**Meta:** distinguir reconocer una acción de atacar la identidad.

**Aprende:** puedes reconocer «hice algo que dañó» sin concluir «soy una persona sin valor». La responsabilidad incluye escuchar el impacto y cambiar lo que puedas. No significa responsabilizarte de lo que hicieron otros.

**Caso resuelto:** Diego rompe un material por usarlo sin permiso. Puede reconocer el hecho, avisar y colaborar en una reparación acordada. Su tristeza no sustituye la reparación; la reparación tampoco exige humillarlo.

**Practica:** a) Cambia «soy malo» por una frase responsable. b) Si otro niño rompe el material, ¿te corresponde aceptar la culpa para que se calme?

**Respuestas:** a) «Usé el material sin permiso y se rompió; necesito ayudar a resolverlo». b) No. Se describen los hechos y se busca ayuda sin asumir una responsabilidad ajena.

**En KiteWise:** separar «acción», «impacto» y «siguiente paso», sin etiquetas permanentes sobre personajes.

### E4.4 · Cambiar el plan sin perder el objetivo

**Meta:** diferenciar objetivo y método.

**Aprende:** a veces una forma de hacer algo no funciona. Puedes cambiar el método, pedir una adaptación o renegociar el objetivo. Ser flexible no significa aceptar una situación insegura o injusta.

**Caso resuelto:** el equipo quería grabar una explicación oral, pero un integrante prefiere escribir. Pueden combinar texto narrado por otra persona con dibujos. El objetivo era explicar el experimento, no obligar a todos a grabarse.

**Practica:** a) ¿Qué se conserva en el caso? b) ¿Qué cambia? c) ¿Cuándo no basta con «adaptarse»?

**Respuestas:** a) Explicar el experimento. b) La forma de participar. c) Cuando hay daño, exclusión o falta de condiciones básicas; hay que cambiar también esas condiciones.

**En KiteWise:** diferentes rutas para producir una misma evidencia de aprendizaje.

### E4.5 · Qué puedo hacer, qué puedo pedir

**Meta:** distinguir acción propia, apoyo compartido y cosas fuera del control inmediato.

**Aprende:** no decides todo lo que sucede. Puedes influir en algunas partes y pedir ayuda en otras. Esta distinción sirve para organizar acciones, no para abandonar un problema que necesita una respuesta colectiva.

**Caso resuelto:** llueve el día de una actividad. No puedes detener la lluvia. Puedes proteger los materiales; el adulto puede buscar otro espacio. La decepción puede seguir presente.

**Practica:** a) ¿Qué acción propia aparece? b) Si hay una norma injusta, ¿debe ignorarse porque un niño no puede cambiarla solo?

**Respuestas:** a) Proteger los materiales. b) No. Puede pedir apoyo para plantear el problema y buscar cambios con otras personas.

**En KiteWise:** tres zonas: «puedo hacer», «necesito que hagamos» y «no depende de mí ahora». Evitar una división simplista entre controlar y resignarse.

### E4.6 · Escuchar sin absorberlo todo

**Meta:** ofrecer presencia respetando límites propios y ajenos.

**Aprende:** acompañar puede ser escuchar, preguntar qué necesita alguien o buscar a un adulto. No tienes que sentir exactamente lo mismo ni solucionar su vida. Puedes decir que no sabes qué responder.

**Caso resuelto:** Sol escucha que su amigo está triste y pregunta: «¿Quieres que me quede o que busquemos a la maestra?». No promete guardar cualquier secreto ni se convierte en su única ayuda.

**Practica:** a) ¿Debes seguir escuchando si una conversación te supera? b) ¿Qué puedes decir?

**Respuestas:** a) No; puedes buscar apoyo. b) «Me importas y necesito que nos ayude un adulto». Si alguien corre peligro, se informa aunque haya pedido secreto.

**En KiteWise:** diálogo ramificado con opción de acompañar, poner un límite y sumar apoyo. No asignar al jugador el papel de terapeuta.

### E4.7 · Reparar sin exigir perdón

**Meta:** formular una reparación concreta y respetuosa.

**Aprende:** una disculpa puede reconocer qué pasó y su impacto. Reparar añade una acción posible y un cambio para el futuro. La persona afectada puede necesitar tiempo y no está obligada a perdonar, abrazar o retomar una amistad.

**Caso resuelto:** Leo borró una parte del dibujo compartido. Dice: «Borré tu trabajo sin preguntarte. Entiendo que te molestara. Puedo ayudarte a reconstruirlo si quieres. La próxima vez preguntaré». El compañero puede rechazar esa ayuda concreta y pedir otra solución.

**Practica:** a) ¿«Perdón si te ofendiste» reconoce la acción? b) Propón una reparación para interrumpir repetidamente a alguien.

**Respuestas:** a) No con claridad. b) Reconocer las interrupciones y organizar turnos, sin obligar al otro a aceptar de inmediato.

**En KiteWise:** construir disculpa, propuesta y prevención; no desbloquear una recompensa solo si el otro personaje perdona.

### E4.8 · Proyecto: un plan que puede cambiar

**Meta:** probar un apoyo, revisar el resultado y elegir otro si hace falta.

**Aprende:** un plan revisable describe qué intentamos facilitar y cómo sabremos si ayuda. Puede cambiar el método, el entorno o los apoyos. No obliga a sentir una emoción determinada para considerar que hubo aprendizaje.

**Caso:** una exposición cambia de lugar. El nuevo salón tiene más ruido. Un personaje se siente sobrepasado y la primera herramienta no le ayuda.

**Ejemplo resuelto:** 1) Pedir apoyo. 2) Bajar el ruido o buscar un lugar distinto. 3) Elegir explicar con un compañero o mediante una grabación preparada. 4) Revisar después qué facilitó la participación. No se exige terminar la exposición si faltan condiciones seguras.

**Practica:** a) ¿Que falle una herramienta significa que el personaje no se esforzó? b) ¿Qué cambio depende del adulto?

**Respuestas:** a) No. b) Organización del lugar, ajustes y apoyo durante la actividad.

**Entrega:** plan A, plan B y una condición que necesita cambiar en el entorno. Puede incluir una reparación si alguien se burló.

**En KiteWise:** versiones del plan y comparación de apoyos; sin calificar cuánto tardó en «volver a la calma».

**Transferencia opcional de 4.º:** transforma un juego de reglas rígidas en otro que permita dos formas equivalentes de participar.

## 8. Quinto grado · Presión, comparación y cuidado

### E5.1 · Un vocabulario más preciso

**Meta:** describir matices sin obligarse a usar una palabra exacta.

**Aprende:** «mal» puede significar decepción, preocupación, soledad, cansancio o varias cosas. Un vocabulario más amplio puede ayudar a expresar una necesidad, pero no hay una palabra correcta que debas descubrir para merecer ayuda. También puedes describir sensaciones o una situación.

**Caso resuelto:** un personaje dice que está «mal» porque quería participar y no lo eligieron. Después decide que «decepcionado» se acerca a lo que siente y pide conocer otras oportunidades. Puede también cuestionar el proceso de selección si no fue justo.

**Practica:** a) Propón dos palabras posibles para esa situación sin afirmar que son obligatorias. b) ¿Qué harías si ninguna palabra encaja?

**Respuestas:** a) Decepción, tristeza, enojo o vergüenza son posibilidades, no diagnósticos. b) Describir la experiencia, inventar una metáfora o pedir tiempo.

**En KiteWise:** palabras con ejemplos cotidianos, búsqueda por significado y opción de escribir una descripción propia.

### E5.2 · Compararme sin reducirme a un resultado

**Meta:** reconocer información útil y límites de una comparación.

**Aprende:** una comparación muestra una parte de una situación. No revela siempre cuánto apoyo, tiempo o experiencia tuvo cada persona. Una nota, un dibujo o una cantidad de seguidores no representa todo el valor de alguien.

**Caso resuelto:** Alex compara su primer dibujo con el de alguien que practica desde hace años. Puede estudiar una técnica del dibujo y elegir una meta propia, en vez de concluir que no debe dibujar. También puede sentir envidia o decepción sin avergonzarse por ello.

**Practica:** a) ¿Qué información faltaba? b) Escribe una comparación útil centrada en una habilidad.

**Respuestas:** a) Experiencia y apoyos, entre otras condiciones. b) «Quiero aprender cómo mezcló esos colores». No es obligatorio comparar ni competir para aprender.

**En KiteWise:** observar versiones anteriores de una creación solo con consentimiento; sin clasificar públicamente estados emocionales ni talentos.

### E5.3 · Perfeccionismo y criterios suficientes

**Meta:** distinguir una meta concreta de una exigencia imposible.

**Aprende:** revisar un trabajo puede ayudar; sentir que nunca está suficientemente bien puede hacer difícil empezarlo o terminarlo. Conviene conocer los criterios, dividir pasos y acordar cuándo detener una revisión. Descansar o pedir una adaptación puede ser parte del plan.

**Caso resuelto:** una tarea pide explicar tres ideas. Sol escribe esas tres y revisa que sean comprensibles. No necesita rehacerla diez veces para garantizar que nadie encuentre un error. La maestra aclara qué se espera y ofrece retroalimentación.

**Practica:** a) Escribe un criterio verificable para un cartel. b) ¿«Que a todo el mundo le encante» depende totalmente de quien lo hace?

**Respuestas:** a) Que incluya fecha y lugar legibles, por ejemplo. b) No. El criterio debe centrarse en algo razonable y revisable.

**En KiteWise:** lista corta de criterios y botón de guardar borrador; sin premiar revisiones interminables.

### E5.4 · Estrés y carga acumulada

**Meta:** identificar demandas y apoyos de una semana ficticia.

**Aprende:** varias demandas juntas pueden hacer que una situación se vuelva más difícil. No todo depende de una herramienta personal. Puede ser necesario reducir tareas, aclarar expectativas o recibir ayuda. Descanso, alimentación, movimiento accesible y relaciones de apoyo forman parte del contexto, sin garantizar que todo malestar desaparezca. [R6–R7]

**Caso resuelto:** un personaje tiene tres entregas, un cambio de horario y poco tiempo de descanso. En vez de añadirle cinco ejercicios de calma como otra obligación, el adulto le ayuda a negociar plazos y escoger un primer paso.

**Practica:** a) Nombra una demanda y un apoyo. b) ¿Se resuelve una sobrecarga solo pidiendo «más actitud»?

**Respuestas:** a) Demanda: entregas simultáneas. Apoyo: ajustar plazos o dividir tareas. b) No. Hay que revisar condiciones reales.

**En KiteWise:** tablero de semana de un personaje; permitir retirar, mover o compartir tareas, además de añadir apoyos.

### E5.5 · Presión de grupo y límites

**Meta:** ensayar una respuesta breve y una salida con apoyo.

**Aprende:** querer pertenecer puede hacer difícil decir que no. Puedes rechazar una acción aunque tus amigos insistan. No necesitas una explicación larga ni quedarte discutiendo. Si te amenazan o te impiden salir, corresponde buscar protección adulta.

**Caso resuelto:** un grupo insiste en publicar una foto que humilla a otra persona. Dani responde: «No voy a compartirla», sale de la conversación y avisa a un adulto. No tiene que demostrar valentía enfrentando solo al grupo.

**Practica:** a) Escribe una negativa breve. b) ¿Qué puede hacer quien se quedó paralizado y no respondió en el momento?

**Respuestas:** a) «No participo» o «No quiero hacerlo». b) Buscar ayuda después. No haber podido responder no convierte a la persona en responsable de una amenaza.

**En KiteWise:** diálogo de presión ficticia; puntuar reconocimiento y apoyo, sin recompensar confrontaciones arriesgadas.

### E5.6 · Emociones y vida digital

**Meta:** reconocer cuándo un contenido o interacción necesita una pausa o intervención.

**Aprende:** los mensajes y las imágenes muestran información parcial. Una respuesta rápida puede aumentar un conflicto. Puedes pausar, silenciar o salir con apoyo. Si hay acoso, amenazas o difusión sin permiso, también hace falta atender la conducta y las condiciones de seguridad; desconectarte no vuelve aceptable lo ocurrido. [R8]

**Caso resuelto:** un personaje ve una conversación que le altera y quiere responder a todos. Decide no enviarlo todavía, consulta a un adulto y acuerda cómo abordar el problema sin redistribuir el contenido dañino.

**Practica:** a) ¿Salir de una aplicación significa renunciar a pedir ayuda? b) ¿Necesitas revisar mensajes hirientes una y otra vez para demostrar qué ocurrió?

**Respuestas:** a) No. b) No. Un adulto puede ayudar a manejar la información necesaria sin que el niño tenga que exponerse repetidamente.

**En KiteWise:** simulador cerrado sin cuentas reales, contactos ni conexión con redes sociales.

### E5.7 · Cambios, pérdidas y tristeza

**Meta:** reconocer distintas respuestas ante una pérdida y ofrecer apoyo sin forzar bienestar.

**Aprende:** extrañar puede aparecer al cambiar de escuela, separarse de alguien o perder algo importante. Ante una muerte, el duelo puede incluir sentimientos que cambian y vuelven. No existe un calendario igual para todos ni etapas que deban completarse en orden. Un adulto debe ofrecer información clara y adecuada; no es tarea del estudiante explicar una muerte real al grupo. [R9]

**Caso resuelto:** un personaje extraña a su mascota fallecida. Puede querer hablar, dibujar un recuerdo o no hacer una actividad con ese tema. Reír después no significa que dejó de quererla.

**Practica:** a) ¿Sirve exigir «ya pasó, alégrate»? b) Propón una frase de compañía.

**Respuestas:** a) No. b) «Puedo acompañarte; no tienes que hablar ahora». No imponer una creencia sobre la muerte como respuesta universal.

**En KiteWise:** actividad opcional de recuerdos, con caso alternativo sin pérdida y salida inmediata.

### E5.8 · Proyecto: un plan de equilibrio

**Meta:** organizar demandas, apoyos y una forma de revisar el plan.

**Aprende:** organizar no consiste en llenar cada minuto. Un plan debe considerar descanso, necesidades y condiciones reales. Algunas decisiones requieren acuerdos con adultos; no corresponde al estudiante arreglar solo una sobrecarga que otros pueden ayudar a cambiar.

**Caso:** una estudiante prepara una feria, tiene tareas y recibe presión para seguir conectada al chat durante la noche. Dice que se siente cansada y preocupada.

**Ejemplo resuelto:** identificar tareas necesarias; pedir ajuste de un plazo; acordar un momento para salir del chat con apoyo adulto; preparar materiales en pasos; reservar descanso. No se asume que puede controlar sola los horarios del hogar.

**Practica:** a) ¿Qué parte necesita cooperación de adultos? b) ¿El plan debe garantizar una semana feliz?

**Respuestas:** a) Plazos, carga y acuerdos de disponibilidad, entre otras. b) No. Debe ser viable, cuidar necesidades y poder revisarse.

**Entrega:** calendario de personaje con dos demandas, dos apoyos, una petición y una revisión. Explica qué se cambia si no funciona.

**En KiteWise:** tablero editable sin puntaje por productividad ni rachas por reportar buen ánimo.

**Transferencia opcional de 5.º:** diseña un cartel de grupo que permita decir «no puedo responder ahora» sin castigar ni excluir.

## 9. Sexto grado · Decisiones, valores y ayuda

### E6.1 · No saber todavía

**Meta:** distinguir una pregunta abierta de una certeza negativa.

**Aprende:** la incertidumbre puede incomodar. Puedes reunir información disponible, preparar una acción y reconocer lo que aún no sabes. No tienes que reemplazar una predicción negativa por una garantía positiva.

**Caso resuelto:** «No sé quién estará en mi próxima clase» es una incertidumbre. «Seguro nadie me hablará» es una predicción. «Podría conocer a alguien y puedo pedir apoyo para incorporarme» reconoce posibilidad sin prometer un resultado.

**Practica:** a) Reescribe «todo saldrá mal» sin garantizar que todo salga bien. b) ¿Se debe aplicar este ejercicio para ignorar una amenaza concreta?

**Respuestas:** a) «No sé cómo saldrá; puedo preparar esta parte y pedir ayuda». b) No. Una amenaza requiere protección, aunque haya información incompleta.

**En KiteWise:** tablero con «sé», «no sé» y «puedo preguntar»; no pedir imaginar el peor escenario como obligación.

### E6.2 · Pensamiento no equivale a instrucción

**Meta:** observar una idea sin tener que actuar según ella.

**Aprende:** una idea puede aparecer rápido y repetirse. No necesitas creerla por completo ni discutir con ella a cada momento. Puedes reconocer «estoy teniendo la idea de que no puedo» y elegir pedir una explicación. Eso no garantiza que deje de aparecer.

**Caso resuelto:** un personaje piensa «si pregunto, se reirán». Puede notar la idea y pedir ayuda por escrito o en privado. El adulto también debe cuidar que no se burlen de las preguntas.

**Practica:** a) ¿Notar una idea obliga a obedecerla? b) ¿Por qué no basta decir «cambia tu mente» si el grupo sí se burla?

**Respuestas:** a) No. b) Porque existe una conducta del entorno que debe detenerse. Una herramienta de pensamiento no sustituye ese cambio.

**En KiteWise:** globos de pensamiento editables de personajes. No se presenta como terapia ni se solicita narrar pensamientos íntimos.

### E6.3 · Valores y decisiones pequeñas

**Meta:** conectar un valor elegido con una acción concreta.

**Aprende:** un valor expresa algo que te importa, como cuidado, curiosidad, justicia o honestidad. Puede orientar decisiones incluso cuando hay emociones difíciles. Los valores no justifican imponer daño ni exigir sacrificios ilimitados.

**Caso resuelto:** Ana valora aprender y teme equivocarse. Elige formular una pregunta por escrito. También valora cuidarse: si está agotada, puede pedir una pausa. Aprender y descansar no tienen que ser enemigos.

**Practica:** a) Elige un valor para un personaje y una acción pequeña. b) ¿Ayudar significa aceptar cualquier petición?

**Respuestas:** a) Por ejemplo, justicia → pedir turnos de participación accesibles. b) No; los límites también pueden proteger a las personas.

**En KiteWise:** seleccionar valores de una lista abierta y asociar acciones; sin clasificar al niño como más o menos moral por sus elecciones.

### E6.4 · Un patrón no es una etiqueta

**Meta:** observar una secuencia de situaciones sin diagnosticar.

**Aprende:** revisar varias ocasiones puede revelar condiciones que se repiten: instrucciones rápidas, poco descanso o un horario difícil. Un patrón ayuda a formular preguntas, pero no prueba una causa ni un diagnóstico. Puede cambiar con nuevos apoyos.

**Caso resuelto:** en tres historias, una estudiante se desconecta cuando recibe varias instrucciones orales a la vez. Se prueba un esquema escrito. Si participa mejor, hay una pista útil, no una demostración de una condición clínica.

**Practica:** a) ¿Qué dato falta para concluir una causa? b) ¿Hace falta un diagnóstico para ofrecer una consigna más clara?

**Respuestas:** a) Falta información de otras condiciones y situaciones; una observación aislada no basta. b) No; se pueden ofrecer apoyos accesibles.

**En KiteWise:** análisis de datos ficticios, sin gráficos automáticos de «riesgo emocional» del usuario.

### E6.5 · Desacuerdo, agresión y acoso

**Meta:** distinguir situaciones sin condicionar el derecho a recibir ayuda.

**Aprende:** un desacuerdo puede requerir conversación y acuerdos. Una agresión necesita detener el daño. El acoso escolar incluye desequilibrio de poder y repetición o posibilidad de repetirse. No todo conflicto es acoso, pero no hace falta esperar a que se repita un daño para pedir protección. [R10]

**Caso resuelto:** dos compañeros discrepan sobre un color: pueden buscar un acuerdo. Un grupo amenaza repetidamente a alguien usando su popularidad para aislarlo: requiere intervención adulta; no se propone una mediación entre partes como si tuvieran la misma seguridad y poder.

**Practica:** a) ¿Una agresión única puede necesitar ayuda? b) ¿Corresponde enseñar solo al afectado a «calmarse»?

**Respuestas:** a) Sí. b) No; hay que detener la conducta y ofrecer protección. La víctima no es responsable de resolver el acoso mediante autorregulación.

**En KiteWise:** escenarios con ayuda adulta explícita, sin pedir al niño que confronte al agresor ni que pruebe jurídicamente una etiqueta.

### E6.6 · Acompañar a un amigo con límites

**Meta:** ofrecer apoyo y reconocer cuándo sumarlo a una red adulta.

**Aprende:** puedes escuchar, preguntar y acompañar a buscar ayuda. No eres terapeuta ni tienes que estar disponible siempre. Si un amigo dice que está en peligro o que quiere hacerse daño, busca de inmediato a un adulto responsable; no prometas mantenerlo en secreto. No necesitas evaluar por tu cuenta qué tan serio es.

**Caso resuelto:** un amigo cuenta una situación que preocupa a Mara. Ella dice: «Me importas; esto necesita ayuda de una persona adulta. Puedo acompañarte a buscarla». Si la primera no responde, busca otra. Ante peligro inmediato, el adulto debe activar ayuda urgente apropiada. [R11]

**Practica:** a) ¿La amistad exige guardar un secreto peligroso? b) ¿Se puede pedir ayuda aunque el amigo se moleste?

**Respuestas:** a) No. b) Sí; proteger y sumar apoyo puede ser necesario. La responsabilidad de actuar recae en adultos y servicios adecuados.

**En KiteWise:** una escena breve no gráfica; sin pedir relatos personales ni simular una crisis para ganar puntos.

### E6.7 · Pedir ayuda profesional sin etiquetas

**Meta:** reconocer que algunos problemas necesitan apoyos adicionales.

**Aprende:** si el malestar persiste, te causa mucho sufrimiento o dificulta dormir, aprender, jugar o relacionarte, puedes pedir a un adulto que busque orientación profesional. No hace falta esperar a estar peor. Si hay peligro, se pide ayuda inmediata. Una app o un cuestionario escolar no determina un diagnóstico. [R11]

**Caso resuelto:** un personaje lleva tiempo sin poder participar en actividades que antes disfrutaba y quiere ayuda. Un adulto escucha, describe observaciones y busca orientación con el equipo escolar o de salud, sin anunciarle una etiqueta a partir del juego.

**Practica:** a) ¿Pedir ayuda significa fallar en las herramientas? b) ¿Qué frase inicial podría usar?

**Respuestas:** a) No. b) «Esto me está costando y necesito más ayuda». No debe probar una duración exacta ni completar todas las lecciones antes de recibir atención.

**En KiteWise:** información clara de alcance y un plan para buscar a una persona real; ningún botón promete atención humana que no exista.

### E6.8 · Proyecto: manual personal de apoyo

**Meta:** integrar señales posibles, apoyos, ajustes y revisión sin crear un expediente íntimo obligatorio.

**Aprende:** un manual de apoyo reúne opciones y vías de ayuda. No es una promesa de no volver a necesitar compañía. Puedes aprender a preparar y revisar un plan usando un personaje, sin describir tu vida privada.

**Caso:** diseña el manual para un personaje que empezará una etapa escolar nueva. Si prefieres, puedes hacer una versión personal y conservarla fuera de la app.

**Ejemplo resuelto:** «Cuando hay muchas instrucciones me cuesta empezar. Puedo pedir un esquema. Si no puedo explicarlo, mostraré una tarjeta. Si no funciona, pediré revisar la tarea. Para un problema de seguridad buscaré a un adulto, sin esperar a estar tranquilo».

**Practica:** a) ¿Es un contrato para no volver a desbordarse? b) ¿Qué se revisa si deja de ayudar?

**Respuestas:** a) No. b) Herramientas, entorno, carga y personas de apoyo. El manual puede cambiar.

**Entrega:** señal o situación, dos opciones, un ajuste ambiental, una petición, un rol adulto y un siguiente paso si no funciona. Se evalúa la coherencia del plan ficticio, no la intimidad revelada.

**En KiteWise:** guardar solo si se solicita y mostrar quién puede verlo; permitir borrar o exportar.

**Transferencia opcional de 6.º:** ensaya con un compañero cómo pedir una adaptación para una tarea ficticia. Nadie tiene que explicar una condición médica o familiar.

## 10. Doce talleres para practicar con las manos y la imaginación

Los talleres permiten aplicar las ideas sin convertir cada encuentro en una conversación personal. Se pueden realizar con papel, fichas o materiales de arte. Cada uno ofrece una alternativa para quien prefiera observar o trabajar con un personaje.

### T01 · Laboratorio de palabras y escenas

**Nivel sugerido:** 1.º–2.º. **Materiales:** escenas, tarjetas vacías y lápices.

**Consigna:** un personaje pierde un turno, otro recibe una sorpresa y otro comienza una actividad nueva. Elige posibles palabras; después lee qué dice cada personaje sobre sí mismo.

**Pasos:** observar el contexto; proponer posibilidades; escuchar el relato; corregir si hace falta; dibujar una pregunta respetuosa. Las tarjetas no asocian automáticamente una cara con una emoción.

**Ejemplo:** el personaje que sonríe cuenta que está nervioso. Se respeta su relato. La sonrisa no lo invalida.

**Práctica y respuesta:** «¿Cuál pregunta es más útil: “sé que estás feliz” o “quieres contarme cómo estás”?». La segunda deja espacio a su experiencia; también puede preferir no responder.

**Evidencia:** propone posibilidades y respeta información nueva. **Variante digital:** escenas con audio de personajes; no reconocimiento facial. **Adaptación:** elegir símbolos o responder con un comunicador.

### T02 · Mapa de pistas, sin código secreto

**Nivel:** 1.º–3.º. **Materiales:** silueta de personaje o un objeto dibujado.

**Consigna:** en una historia, el personaje siente calor, aprieta las manos y pide compañía. Marca las pistas que él menciona. No inventes una explicación médica o emocional.

**Pasos:** leer; localizar las pistas; preguntar qué información falta; elegir un apoyo. Si trabajar con el cuerpo incomoda, usar tarjetas de contexto: ruido, instrucciones, cambios y descanso.

**Ejemplo:** «Tiene manos apretadas, por eso sabemos que está enojado» se revisa a «Es una pista; necesitamos escuchar qué cuenta».

**Práctica y respuesta:** «¿Una sensación tiene siempre una sola causa?». No. «¿Puedo pedir ayuda antes de entenderla?». Sí.

**Evidencia:** distingue observación e interpretación. **Variante digital:** dibujo libre con etiquetas; sin conservar un mapa corporal personal por defecto. **Cuidado:** una molestia física real se comunica a un adulto, no se procesa como un error del juego.

### T03 · Diseña un rincón de apoyo

**Nivel:** 1.º–4.º. **Materiales:** plano simple, fichas de muebles y tarjetas de opciones.

**Consigna:** crea un espacio de uso voluntario que permita compañía, accesibilidad y regreso flexible a la actividad.

**Pasos:** elegir ubicación segura; reducir distracciones cuando sea posible; dejar una salida libre; añadir formas de pedir ayuda; decidir cómo avisar que se necesita más apoyo. No se encierra ni se manda a nadie como castigo.

**Ejemplo:** una silla cercana al adulto y una tarjeta de comunicación pueden servir más que una sala llena de luces y sonidos. Un objeto «sensorial» no ayuda automáticamente a todos.

**Práctica y respuesta:** «¿Puede alguien elegir no entrar?». Sí. «¿Debe quedarse hasta sonreír?». No.

**Evidencia:** el diseño respeta elección, seguridad y acompañamiento. **Variante digital:** maqueta arrastrable con revisión de acceso y rutas; alternativa de botones. El espacio físico debe revisarlo un adulto responsable.

### T04 · Menú de herramientas, sin receta única

**Nivel:** 2.º–4.º. **Materiales:** tarjetas de movimiento cómodo, pausa, dibujo, compañía, respiración opcional y cambios del entorno.

**Consigna:** ayuda a dos personajes con necesidades distintas. Uno quiere menos ruido; otro quiere que le expliquen el siguiente paso.

**Pasos:** escuchar qué pide cada uno; escoger una opción coherente; imaginar que no ayuda; elegir otra o sumar apoyo adulto. No se realiza cada ejercicio sobre el propio cuerpo para completar el taller.

**Ejemplo:** ofrecer respirar a quien pide aclarar la consigna no atiende por sí solo la necesidad. Puede servir como opción adicional si la persona la desea.

**Práctica y respuesta:** «¿Cuántas herramientas hay que probar antes de merecer ayuda?». Ninguna cantidad mínima. Pedir ayuda puede ser el primer paso.

**Evidencia:** conecta necesidad y apoyo. **Variante digital:** menú editable con «ninguna de estas»; sin clasificación universal de la herramienta más efectiva.

### T05 · Estudio de sonido, color y ritmo

**Nivel:** 2.º–6.º. **Materiales:** lápices, papel, percusión suave opcional o herramientas de arte digitales.

**Consigna:** representa el estado de un personaje mediante líneas, colores o un ritmo. Después escribe o cuenta qué significa para ti esa representación.

**Pasos:** elegir un personaje; seleccionar medio; crear sin obligación de realismo; describir el significado; decidir si compartir. Se admite una pieza silenciosa o sin color.

**Ejemplo:** el azul puede representar alegría para un estudiante y tristeza para otro. El color no revela una emoción oculta ni una experiencia clínica.

**Práctica y respuesta:** «¿Podemos afirmar lo que alguien siente por el color que eligió?». No; preguntamos si quiere explicar. «¿La música tiene que calmar?». No; aquí sirve para explorar expresión y elección.

**Evidencia:** relaciona intención y forma de expresión sin juzgar emociones. **Variante digital:** puente con Artes: capas, pinceles y secuenciador opcional con volumen controlable y sin reproducción inesperada.

### T06 · Cine de pensamientos y hechos

**Nivel:** 3.º–6.º. **Materiales:** viñetas y globos removibles.

**Consigna:** un personaje ve que otros se ríen mientras entra. Se sabe que se ríen; todavía no se sabe de qué. Construye dos versiones y luego añade información.

**Pasos:** escribir el hecho; añadir una interpretación; nombrar solo la emoción que el personaje expresa; proponer una pregunta o ayuda; revelar un detalle. Una versión puede confirmar una burla: en ella hay que intervenir, no reinterpretarla como inocente.

**Ejemplo:** versión A: recuerdan un chiste anterior. Versión B: se burlan del personaje. El mismo dato inicial no autorizaba certeza; la información nueva cambia el plan.

**Práctica y respuesta:** «¿Pensar otra explicación elimina una burla real?». No.

**Evidencia:** actualiza la interpretación y distingue protección de pensamiento positivo. **Variante digital:** montar dos finales de cómic y comparar qué apoyos necesita cada uno.

### T07 · Una tarea con dos caminos

**Nivel:** 3.º–6.º. **Materiales:** rompecabezas o desafío creativo de baja dificultad.

**Consigna:** completa un objetivo utilizando dos métodos posibles y con apoyos disponibles. El taller no busca provocar un desborde real.

**Pasos:** presentar el objetivo y las opciones; modelar una dificultad pequeña; elegir pedir pista, cambiar método o pausar; revisar qué se modificó. Si aparece malestar importante, se detiene y se acompaña.

**Ejemplo:** armar un modelo con bloques o dibujarlo. Si una pieza no encaja, puede cambiar la pieza o la representación. No se aumenta la dificultad a propósito para comprobar «tolerancia».

**Práctica y respuesta:** «¿Seguir sin descanso prueba más aprendizaje?». No. Importa comprender el objetivo y usar apoyos adecuados.

**Evidencia:** propone un cambio concreto. **Variante digital:** pistas gratuitas y restauración de versiones. El sistema no destruye el trabajo para generar frustración artificial.

### T08 · Mesa de reparación

**Nivel:** 4.º–6.º. **Materiales:** personajes y tarjetas de hecho, impacto, reparación y prevención.

**Consigna:** en una historia, alguien interrumpe y modifica una creación ajena sin permiso. Diseña una respuesta que reconozca lo ocurrido y respete a la persona afectada.

**Pasos:** describir sin insultos; escuchar el impacto expresado; proponer una acción viable; preguntar si esa acción es aceptable; acordar un cambio. No se usa para recrear un acoso real ni obligar a la víctima a conversar.

**Ejemplo:** recuperar una versión anterior, preguntar antes de editar y establecer permisos. «Te pido perdón, así que tienes que jugar conmigo» no es reparación respetuosa.

**Práctica y respuesta:** «¿Quién decide si quiere aceptar un abrazo?». La persona a quien se ofrece; nunca es obligatorio.

**Evidencia:** reconoce impacto y límites. **Variante digital:** restaurar la obra y configurar permisos en una colaboración ficticia, sin exigir perdón para completar.

### T09 · El taller de frases justas

**Nivel:** 3.º–6.º. **Materiales:** frases de personajes y espacio para reescribir.

**Consigna:** sustituye etiquetas globales por descripciones concretas y apoyos posibles, sin negar una dificultad.

**Pasos:** localizar la etiqueta; identificar el hecho conocido; proponer una frase respetuosa; añadir una acción; señalar si el entorno necesita cambiar. Evitar «puedo todo si quiero» como solución general.

**Ejemplo:** «Soy un fracaso porque no terminé» cambia a «No terminé esta tarea; necesito revisar el tiempo, la dificultad y los apoyos». Si el tiempo asignado fue insuficiente, no se atribuye todo al estudiante.

**Práctica y respuesta:** «¿Una frase respetuosa tiene que ser exageradamente positiva?». No; debe ser creíble y útil. «¿Cambiar palabras reemplaza una adaptación?». No.

**Evidencia:** separa identidad y acción, y reconoce condiciones. **Variante digital:** editor libre o tarjetas; el evaluador revisa significado, no coincidencia literal con una frase modelo.

### T10 · Una semana con espacio para vivir

**Nivel:** 5.º–6.º. **Materiales:** calendario de personaje, demandas y apoyos.

**Consigna:** el personaje tiene actividades que se superponen, poco descanso y una tarea que no entiende. Ajusta el plan con cooperación adulta.

**Pasos:** identificar necesidades; distinguir compromisos y opciones; mover o reducir una demanda; añadir un apoyo concreto; revisar qué ocurre si cambia un día. No usar datos reales del hogar.

**Ejemplo:** reorganizar una entrega puede ayudar más que llenar cada espacio libre con ejercicios. Un tiempo sin planificar no necesita convertirse en otra tarea productiva.

**Práctica y respuesta:** «¿El mejor calendario es el que tiene más actividades?». No; debe ser viable y dejar lugar al cuidado, descanso y participación. «¿Puede el estudiante cambiar solo todos los horarios?». No; necesita acuerdos.

**Evidencia:** reconoce límites y pide cooperación. **Variante digital:** agenda arrastrable sin ranking de productividad y sin penalización por eliminar una actividad opcional.

### T11 · Teatro de pedir ayuda

**Nivel:** 1.º–6.º, con complejidad graduada. **Materiales:** tarjetas de roles, títeres o diálogo escrito.

**Consigna:** un personaje pide ayuda y el primer adulto no está disponible. Ensaya un segundo camino. En mayores, añade una situación que requiere protección y no debe guardarse como secreto.

**Pasos:** elegir cómo comunicar; formular petición; localizar un rol alternativo; acompañar sin prometer confidencialidad absoluta. Se pueden omitir escenas y observar.

**Ejemplo:** «Necesito ayuda ahora con una situación que me hace sentir inseguro». El adulto escucha y decide los pasos de protección apropiados. No pide al niño que investigue ni confronte a quien le hizo daño.

**Práctica y respuesta:** «¿Una primera respuesta que no ayuda cierra todas las opciones?». No; buscar otro adulto. «¿Hay que revelar un caso personal?». No.

**Evidencia:** conoce vías de apoyo. **Variante digital:** mapa de roles ficticios; ningún mensaje se envía fuera del ejercicio.

### T12 · Mi laboratorio de apoyos revisables

**Nivel:** 4.º–6.º. **Materiales:** ficha antes/después y tres escenarios ficticios.

**Consigna:** un personaje quiere participar en un proyecto y algo le dificulta hacerlo. Formula una hipótesis práctica sobre un apoyo, pruébala en una historia y revisa.

**Pasos:** describir la situación; elegir un apoyo; anticipar qué facilitaría; leer qué ocurrió; mantener, modificar o cambiar el plan. El dato no es «se volvió feliz», sino «pudo comunicar lo que necesitaba» o «la consigna siguió sin entenderse».

**Ejemplo:** un esquema escrito facilita iniciar una tarea; en otra escena hace falta además bajar el ruido. No se declara una herramienta universal a partir de un caso.

**Práctica y respuesta:** «¿Si no funciona, hay que repetirla más fuerte?». No; revisar la hipótesis, el contexto y el apoyo disponible.

**Evidencia:** usa la revisión para aprender, sin culpar. **Variante digital:** versiones comparables del plan con relatos predefinidos; no un experimento psicológico automático sobre el usuario.

## 11. Sandbox emocional · Especificación de experiencias

Estas son propuestas concretas para desarrollar en KiteWise. Mantienen el estilo cálido, ilustrativo y sencillo del proyecto: fondo crema, acentos de color, personajes expresivos y pocos detalles. La estética puede invitar a explorar sin convertir la emoción en un objeto que hay que eliminar. Ninguna experiencia depende de arrastrar con precisión: debe existir una alternativa de seleccionar, elegir destino y confirmar.

### S01 · Atlas de emociones y situaciones

**Público:** 1.º–6.º, con vocabulario graduado. **Aprendizaje:** nombrar posibilidades, escuchar autodescripciones y distinguir pistas de certezas.

**Pantalla:** escena cotidiana, relato del personaje, tarjetas y botón «no lo sé». **Bucle:** observar → proponer → escuchar → revisar → preguntar qué apoyo quiere. El relato puede confirmar o cambiar una interpretación inicial.

**Regla de evaluación:** si se pregunta «¿qué dijo sentir el personaje?», se evalúa comprensión del relato. Si se pregunta «¿qué podría sentir?», se admiten posibilidades coherentes. No tratar ambas preguntas como idénticas.

**Caso de aceptación:** personaje sonriente declara «estoy nervioso». La respuesta no se marca incorrecta porque el dibujo muestre sonrisa. **Errores que evitar:** expresiones exageradas como único recurso; asociación universal entre cejas y emoción; «triste» como opción perdedora.

### S02 · Estudio de expresión

**Público:** todos los grados. **Aprendizaje:** representar significados y elegir qué compartir. **Herramientas:** pincel, collage, formas, texto y ritmo opcional. Puente directo con el sandbox de Artes.

**Bucle:** escoger un personaje o tema → crear → añadir significado si se desea → guardar o descartar → compartir solo mediante una decisión explícita. El estudiante puede crear algo abstracto y no explicarlo.

**Regla:** ninguna combinación de color, ritmo o dibujo genera una etiqueta emocional automática. No deducir trauma, personalidad o riesgo a partir de la obra. **Caso de aceptación:** dos estudiantes usan negro con significados distintos; ambos trabajos se guardan sin corregir el color. **Acceso:** volumen apagado inicialmente, sin destellos, botón para reducir movimiento, alternativa de dibujo en papel.

### S03 · Caja de opciones y apoyos

**Público:** 1.º–6.º. **Aprendizaje:** conectar una necesidad expresada con una opción y cambiar si no ayuda.

**Pantalla:** tarjetas «pedir compañía», «aclarar tarea», «menos ruido», «pausa», «movimiento cómodo», «mirar un objeto» y «respiración opcional». No se presenta una lista cerrada de recetas.

**Bucle:** leer necesidad → seleccionar apoyo → recibir relato del personaje → mantener, cambiar o sumar adulto. **Caso de aceptación:** el personaje pide aclarar la consigna; el sistema reconoce que una explicación responde a esa necesidad. Si se elige respirar, explica que podría ser una opción adicional, pero la consigna sigue sin aclararse.

**Salida común:** «Necesito otra opción». No se exige probar todas las tarjetas. El historial personal no se conserva por defecto y no se calcula una puntuación de eficacia emocional.

### S04 · Historias con caminos

**Público:** 3.º–6.º. **Aprendizaje:** diferenciar información, interpretación, elección y consecuencia.

**Pantalla:** cómic con dos o tres caminos por decisión. **Bucle:** leer → separar hecho e idea → elegir acción → obtener información nueva → revisar. Hay historias ambiguas y otras con daño explícito.

**Regla:** las consecuencias no son promesas. Decir algo respetuoso puede no generar una respuesta respetuosa del otro; entonces debe existir una vía de apoyo. **Caso de aceptación:** una amenaza no se resuelve seleccionando «piensa positivo». La vía correcta incluye protección adulta y evita confrontaciones obligatorias.

**Retroalimentación útil:** «Esta opción pide información sin asumir una causa. Si descubres que hay burla, el siguiente paso necesita apoyo». **Retroalimentación a evitar:** «Si elegiste bien, nadie se enoja».

### S05 · Arquitectos de entornos

**Público:** 2.º–6.º. **Aprendizaje:** reconocer que la accesibilidad y el ambiente influyen en la participación.

**Objetos:** plano de aula, volumen, instrucciones, turnos, materiales, formas de comunicar y presencia adulta. **Bucle:** escuchar barrera → adaptar → observar el resultado narrado → revisar. No existe una sala perfecta universal.

**Caso:** un personaje necesita una instrucción visual y otro no tolera un audio repetitivo. Una solución puede ofrecer el esquema y permitir silenciar el audio individualmente. **Caso de aceptación:** un cambio útil para uno no se impone automáticamente a todos; se pueden combinar opciones. No se pide entrenar al niño a tolerar un estímulo doloroso como objetivo del juego.

### S06 · Taller de reparación y acuerdos

**Público:** 4.º–6.º. **Aprendizaje:** reconocer una acción, su impacto y un cambio futuro.

**Pantalla:** situación ficticia, tarjetas de reconocimiento, propuestas y límites. **Bucle:** describir → reconocer impacto → ofrecer reparación → respetar la respuesta → acordar prevención. Se usa para errores y desacuerdos adecuados al contexto; no media acoso real.

**Caso de aceptación:** «no quiero un abrazo» se respeta y no bloquea el cierre. El personaje puede aceptar ayuda material sin perdonar todavía. **Registro:** guardar el producto del ejercicio, no una lista de infracciones reales del estudiante.

### S07 · Mapa de apoyos

**Público:** todos los grados. **Aprendizaje:** encontrar más de una vía de ayuda y reconocer los límites de la app.

**Pantalla:** roles del hogar, escuela, comunidad y profesionales, con personajes ficticios. **Bucle:** elegir necesidad → localizar rol → formular petición → resolver una indisponibilidad → encontrar otra vía.

**Texto explícito de la simulación:** «Estamos practicando. Este ejercicio no envía mensajes. Para pedir ayuda ahora, acércate a una persona adulta de confianza». **Caso de aceptación:** pulsar «pedir ayuda» en el ejercicio no muestra «tu maestro ha sido avisado» si no existe y se ha confirmado esa función. No guardar contactos reales como requisito.

### S08 · Mi plan revisable

**Público:** 3.º–6.º, con versión visual inicial. **Aprendizaje:** reunir lo aprendido y revisar apoyos.

**Campos:** situación, señales opcionales, lo que necesita el personaje, opciones, ajuste del entorno, rol de apoyo y revisión. **Bucle:** preparar → probar con una escena → revisar → guardar o descartar.

**Caso de aceptación:** «no funcionó» abre alternativas y petición de apoyo; no descuenta puntos. La versión ficticia puede completar el aprendizaje sin usar una experiencia personal. Si se ofrece una versión privada, sus condiciones de visibilidad se explican antes de escribir.

### Reglas comunes de producto

| Elemento | Comportamiento esperado |
|---|---|
| Estados emocionales | No son puntuaciones, diagnósticos ni categorías de alumnos |
| Progreso | Se basa en contenidos practicados y comprensión de casos |
| Insignias | Reconocen revisar, justificar o conocer apoyos; nunca «niño siempre feliz» |
| Rachas | No dependen de contar cómo se siente ni de completar ejercicios de calma |
| Tiempo | Sin premio por dejar de llorar rápido ni límite para «regularse» |
| Audio y movimiento | Controlables, opcionales y sin sorpresas intensas |
| Cara, voz y cuerpo | No se usan para inferir estados emocionales ni verificar sinceridad |
| Contenido personal | Opcional; no requerido para desbloquear lecciones |
| Cámara y micrófono | No necesarios; si existe grabación de explicación, alternativa equivalente y decisión explícita |
| Texto libre | No se presenta como un canal de ayuda humana si no lo es |
| Comparaciones | Sin ranking de calma, resiliencia, felicidad o «riesgo» |
| Compartir | Sin galería pública ni envío automático de diarios o creaciones |

## 12. Evaluación del aprendizaje

### Qué se evalúa y qué no

Se evalúa si el estudiante comprende conceptos, distingue información e interpretación, propone apoyos coherentes y reconoce cuándo necesita intervención adulta. Se utilizan personajes. No se califica el estado emocional, el contacto visual, la quietud, la rapidez en hablar, la voluntad de contar una experiencia o la capacidad de quedarse solo durante una pausa.

Un alumno puede explicar perfectamente una estrategia en un ejercicio y no poder usarla en un momento difícil. Eso no demuestra desobediencia ni falsedad: requiere revisar apoyos y contexto. La evaluación educativa no sustituye una valoración profesional. CASEL propone oportunidades explícitas, activas y secuenciadas; la secuencia de este manuscrito debe probarse y ajustarse antes de atribuirle eficacia. [R13]

### Diagnóstico inicial sin nota

Usar tres preguntas sobre un personaje: «¿Qué diferencia hay entre sentir enojo y empujar?», «¿Qué podría necesitar si la consigna le confunde?» y «¿Qué puede hacer si la primera persona no ayuda?». En mayores, añadir: «¿Qué sabemos y qué estamos suponiendo?». Aceptar dibujos, selección de tarjetas o explicación oral. Repetir al final con otra historia equivalente, sin pedir revelar emociones actuales.

### Rúbrica descriptiva de los proyectos

| Dimensión | Necesita modelado | Con guía | Con apoyo puntual | Explica y transfiere |
|---|---|---|---|---|
| Comprensión | Confunde emoción, idea y acción | Las distingue después de un ejemplo | Las distingue en el caso dado | Las explica y reconoce información faltante |
| Apoyos | No identifica opciones todavía | Elige entre opciones muy guiadas | Propone un apoyo coherente | Compara opciones e incluye ajustes del entorno |
| Seguridad y límites | Necesita que se modele la ayuda | Identifica ayuda con preguntas | Reconoce una vía adecuada | Distingue dificultad, daño y necesidad de protección |
| Revisión | Mantiene el plan sin revisarlo | Cambia una parte con guía | Ajusta tras información nueva | Explica qué cambió y cuándo sumar apoyo |

Se usa para el desempeño en la actividad, no para definir la personalidad. «No observado» es distinto de «no sabe»: pasar una pregunta o elegir no participar no autoriza a deducir un déficit emocional. No se combinan estas dimensiones en un índice de bienestar.

### Comprobación de 1.º

1. Teo dice «estoy triste y enojado». ¿Puede sentir ambas cosas?
2. ¿Qué parte es acción: sentir enojo o empujar?
3. Un personaje no encuentra palabras. Da otra forma de pedir ayuda.
4. La primera adulta está ocupada y el problema continúa. ¿Qué puede hacer?

**Respuestas orientativas:** 1) Sí. 2) Empujar. 3) Señalar, dibujar, usar una tarjeta o un comunicador. 4) Buscar otro adulto de confianza. Si hay peligro, necesita ayuda inmediata, sin esperar a terminar el ejercicio.

### Comprobación de 2.º

1. Una herramienta no ayuda a un personaje. ¿Ha fracasado?
2. El ruido le molesta. Nombra un cambio del entorno y una petición.
3. ¿Una pausa es un castigo hasta que sonría?
4. ¿Qué apoyo facilita terminar un juego y pasar a otra actividad?

**Respuestas:** 1) No; puede cambiar herramienta o pedir apoyo. 2) Reducir ruido o cambiar de lugar; «necesito un lugar más tranquilo», por ejemplo. 3) No. 4) Aviso, guardado y explicación del próximo paso. No se exige una frase exacta.

### Comprobación de 3.º

1. Clasifica: «no respondió», «seguro está molesto conmigo» y «me siento preocupado».
2. ¿Qué información falta para saber por qué no respondió?
3. Reescribe «soy incapaz» como descripción concreta y petición.
4. ¿Encontrar una interpretación alternativa justifica ignorar una amenaza?

**Respuestas:** 1) Hecho descrito, interpretación y emoción expresada. 2) Saber qué ocurrió, si escuchó o si podía responder; no hay causa confirmada. 3) «Esta parte me cuesta; necesito un ejemplo», entre otras. 4) No; se busca protección.

### Comprobación de 4.º

1. ¿Alguien puede alegrarse por mudarse y extrañar su escuela?
2. Se modificó una obra sin permiso. Propón reconocimiento y reparación.
3. ¿La persona afectada está obligada a aceptar un abrazo?
4. Una adaptación no funciona. ¿Qué conviene revisar?

**Respuestas:** 1) Sí. 2) Reconocer la modificación y preguntar si quiere ayuda para recuperar una versión, además de pedir permiso en el futuro. 3) No. 4) Herramienta, objetivo, entorno y apoyos; no culpar automáticamente al estudiante.

### Comprobación de 5.º

1. ¿Una comparación con una imagen publicada muestra toda la experiencia de esa persona?
2. Da un criterio verificable para terminar una tarea sin exigir perfección.
3. ¿Qué puede decir un personaje al que presionan para compartir una burla?
4. ¿Disfrutar un momento elimina una pérdida o vuelve falso el duelo?
5. Nombra un ajuste de carga que requiere cooperación adulta.

**Respuestas:** 1) No. 2) Incluir tres ideas claras, por ejemplo, según la tarea. 3) «No voy a compartirla», salir y buscar ayuda si hace falta. También es válido no poder responder y pedir ayuda después. 4) No. 5) Cambiar un plazo, reducir tareas simultáneas o aclarar expectativas.

### Comprobación de 6.º

1. Cambia «seguro todo saldrá mal» por una frase que reconozca incertidumbre sin garantizar éxito.
2. ¿Un patrón de tres escenas permite diagnosticar a alguien?
3. ¿Una agresión única puede requerir protección aunque no se clasifique como acoso?
4. Un amigo cuenta que está en peligro y pide secreto. ¿Qué corresponde?
5. ¿Pedir apoyo profesional demuestra que no aprendió autorregulación?
6. Propón una revisión de un plan que dejó de ayudar.

**Respuestas:** 1) «No sé cómo saldrá; puedo preparar una parte y pedir apoyo». 2) No. 3) Sí. 4) Buscar de inmediato a un adulto responsable; no prometer secreto ni evaluar solo el riesgo. 5) No. 6) Cambiar una herramienta, ajustar condiciones y sumar apoyos, con una razón coherente. No basta exigir más esfuerzo con el mismo plan.

### Retroalimentación que enseña

| Idea a revisar | Respuesta del acompañante | Acción de aprendizaje |
|---|---|---|
| «Enojarse es malo» | «Podemos reconocer el enojo y elegir acciones que cuiden» | Separar emoción y acción |
| «Sé cómo se siente por su cara» | «La cara da pistas; escuchemos qué cuenta» | Revelar el relato del personaje |
| «Si no se calma, no quiere» | «Quizá necesita otro apoyo o un cambio de condiciones» | Revisar tarea y entorno |
| «Respirar siempre funciona» | «Es una opción; hay otras y podemos pedir ayuda» | Ofrecer alternativas |
| «Todo depende de cómo piense» | «También importan los hechos y cómo le tratan» | Identificar cambios del entorno |
| «Pedir ayuda es hacer trampa» | «Saber pedir y usar apoyos forma parte del aprendizaje» | Ensayar una petición |
| «Disculparse obliga a perdonar» | «La reparación respeta también el tiempo y los límites del otro» | Ofrecer sin exigir |
| «La víctima debe resolver el acoso» | «Los adultos tienen responsabilidad de detener el daño» | Identificar una vía de protección |

## 13. Guiones de acompañamiento para adultos

Estos guiones son ejemplos educativos para adaptar. No deben recitarse como una fórmula ni reemplazar los procedimientos de protección del centro. Ofrecer pocas palabras si el niño está sobrepasado; dejar el análisis para después. No tocar ni abrazar sin comprobar si lo acepta.

### A. En el momento de una dificultad

**Escena:** hay mucho ruido y el niño no logra seguir.

«Veo que esto está siendo difícil. Podemos bajar el ruido o buscar otro lugar. Puedo quedarme cerca. Puedes señalar lo que necesitas».

**Acción adulta:** revisar seguridad, reducir demandas y ofrecer opciones. Si hay objetos peligrosos, asegurar el espacio sin convertirlo en una discusión sobre culpa. No pedir una explicación larga ni hacer preguntas sucesivas como examen.

### B. Cuando el niño no quiere hablar

«No tienes que contarlo ahora. Puedes dibujar, usar esta tarjeta o hablar con otra persona de confianza. Sigo disponible».

**Acción:** respetar el silencio y observar necesidades sin interpretar automáticamente su causa. Si existe una preocupación de seguridad, actuar según las responsabilidades del adulto, sin exigir un relato completo para ofrecer protección. [R4]

### C. Después de una acción que dañó

«Sentir enojo no te hace malo. Empujar lastima y hay que detenerlo. Primero veamos que todos estén seguros. Después vamos a entender qué pasó y cómo reparar».

**Acción:** atender a quien recibió el daño, acompañar a quien lo hizo y revisar condiciones. No usar una disculpa obligada como única medida ni exigir un abrazo. La reparación debe ser viable y proporcional, sin exposición pública.

### D. Cuando una herramienta no ayuda

«No parece estar ayudando. Podemos parar. ¿Necesitas otra forma de apoyo o cambiar algo de la actividad?».

**Acción:** revisar ruido, dificultad, instrucciones y necesidades físicas. Si el estudiante no puede elegir, ofrecer una opción simple y acompañar. No introducir cada vez más ejercicios como castigo por no mejorar.

### E. Ante una pérdida

«Puedes extrañar y sentir cosas distintas. No tienes que hablar si no quieres. Puedo acompañarte y responder lo que pueda con claridad».

**Acción:** no imponer una explicación espiritual o una secuencia de etapas. Si se trata de una muerte real, coordinar información clara, apoyos y opciones de participación con los responsables adecuados, respetando creencias y privacidad. [R9]

### F. Cuando pide ayuda por un daño

«Gracias por contármelo. Vamos a buscar cómo cuidarte. No tienes que resolverlo a solas. Voy a explicarte a quién necesito pedir ayuda».

**Acción:** escuchar sin interrogar ni sugerir respuestas, no prometer secreto absoluto y seguir el procedimiento local de protección. No confrontar al supuesto responsable delante del niño ni pedirle que investigue o consiga pruebas por su cuenta.

### G. Cuando el adulto se equivocó

«Levanté la voz y eso pudo asustarte. No estuvo bien. Voy a bajar el tono y buscar otra forma de ayudarte. Si necesitas hablar con otra persona, podemos organizarlo».

**Acción:** reconocer sin exigir que el niño consuele al adulto. La autorregulación del hogar o del aula no se vuelve responsabilidad del estudiante.

## 14. Cuándo sumar ayuda adicional

Esta sección es para adultos responsables. El NIMH aconseja buscar orientación cuando emociones o conductas persisten, causan sufrimiento o interfieren en la vida cotidiana; si hay comportamiento inseguro o expresiones de querer hacerse daño o dañar a otros, se necesita ayuda inmediata. No se debe esperar una duración fija ante una preocupación importante. [R11]

**En la práctica:** escuchar, describir observaciones concretas y consultar al equipo escolar o de salud apropiado. Ante peligro inmediato, priorizar supervisión y ayuda urgente conforme a la situación y los recursos locales. Este manual no proporciona una valoración del riesgo ni instrucciones de tratamiento.

**Límite del producto:** no lanzar un diario libre o asistente conversacional como si fuera atención psicológica. Antes de ofrecer cualquier canal de mensajes personales, debe estar claro quién lo recibe, si alguien lo revisa, en qué horario, sus límites y cómo se atienden comunicaciones de seguridad. Si no existe esa capacidad, la interfaz lo dice y orienta hacia una persona real; no simula una alerta enviada.

## 16. Accesibilidad, privacidad e implementación

### Acceso al aprendizaje

- Texto graduado y narración opcional. En 1.º–2.º, consignas cortas y lectura acompañada; en grados mayores, explicación ampliable.
- Comunicación mediante voz, texto, dibujo, señalamiento o sistemas de comunicación aumentativa.
- No exigir contacto visual, inmovilidad, expresiones faciales específicas o contacto físico.
- Controles grandes, navegación por teclado y lector de pantalla, subtítulos y transcripción de audio.
- Alternativa a cada movimiento corporal y a cada actividad de atención al cuerpo o respiración.
- Sonido, animación y color personalizables; nunca usar color como único portador de significado.
- Botones visibles para pasar, pausar, salir y retomar sin pérdida de una creación.
- El adulto puede modelar sin responder por el niño. Las adaptaciones no descuentan puntos.

### Qué guardar

**Por defecto:** avance por contenidos y respuestas a situaciones ficticias. **Opcional y separado:** una creación o plan que el estudiante haya decidido guardar, con visibilidad explicada. **No necesario:** diario emocional personal, nombres de familiares, salud, conflictos reales o mapas de riesgo.

Si se incorpora una versión personal, definir antes de construir quién accede, cómo se borra, qué se exporta y qué se comunica al estudiante. Un consentimiento genérico de uso no debe ocultar compartir textos íntimos con todo un panel. La adaptación legal y de protección de datos requiere revisión específica del lugar de lanzamiento; aquí no se afirma cumplimiento normativo.

### Si se utiliza IA

La primera versión puede funcionar con relatos y retroalimentaciones revisados, sin conversación abierta. Si después se usa IA, limitar su papel a apoyo educativo supervisado: reformular una consigna, narrar un caso o proponer una variante dentro de contenidos aprobados. No diagnosticar, interpretar dibujos, detectar emociones por cámara o voz, ni actuar como sustituto de una persona de apoyo.

Las respuestas abiertas sobre casos no deben calificarse por coincidir palabra por palabra. Mostrar una respuesta orientativa y ofrecer revisión adulta cuando haya ambigüedad. Un clasificador no debe convertir «enojo» en riesgo automáticamente ni aprobar una acción dañina porque esté redactada con palabras amables.

### Comprobaciones de producto antes de publicar

| Caso de prueba | Resultado esperado |
|---|---|
| El estudiante pulsa «paso» | Continúa con un personaje o alternativa equivalente |
| Una sonrisa acompaña un relato de tristeza | Se respeta el relato, sin corrección por la cara |
| La respiración no ayuda | Se permite parar y cambiar de opción |
| El ruido impide participar | Se ofrecen ajustes del entorno, además de herramientas personales |
| Hay amenaza en la historia | Aparece protección adulta, sin «pensar positivo» como cierre |
| No acepta un abrazo | Su límite se respeta |
| El primer adulto no está disponible | Se practica otra vía de ayuda |
| El niño necesita apoyo aunque explique bien la lección | No se interpreta como contradicción o desobediencia |
| Se sale antes del final | Avance y creación se conservan según la elección del usuario |
| Se pulsa ayuda en una simulación | Se explica que no se envió un mensaje real |
| Se usa lector de pantalla o teclado | Se puede completar el mismo objetivo |
| Se elimina una creación opcional | Se confirma la acción y deja de mostrarse donde corresponda |

Estas comprobaciones son criterios de diseño, no pruebas ya ejecutadas sobre una app implementada.

### Orden de implementación propuesto

1. **Base:** atlas, relatos de 1.º–2.º, peticiones y caja de opciones; controles de accesibilidad y salida desde el inicio.
2. **Aplicación:** historias con caminos, arquitectos de entornos y editor de expresiones conectado con Artes.
3. **Profundización:** reparación, planes revisables y contenidos de 5.º–6.º con evaluación de casos.
4. **Revisión:** probar comprensión, claridad de respuestas y accesibilidad con estudiantes y docentes; revisión por profesionales de desarrollo infantil y protección. Ajustar antes de prometer resultados.

El éxito inicial se observa en si entienden las consignas, distinguen conceptos y pueden encontrar apoyos en los casos. No se mide por reducir reportes de tristeza ni por aumentar el tiempo que pasan en la app.

| Red de apoyo | Support network | Personas y roles que pueden acompañar o ayudar |
| Duelo | Grief | Respuesta a una pérdida, variable entre personas y momentos |
| Acoso escolar | Bullying | Conducta agresiva con desequilibrio de poder y repetición o posibilidad de repetirse |

No confundir *self-regulation* con obediencia, ni *calm* con la única forma válida de estar. La versión inglesa debe revisar naturalidad, variantes culturales y ejemplos; este glosario no sustituye esa traducción.
