# Entrega a Claude Code — Isa y Bella

Importa **La puerta que dejé entreabierta** como un libro independiente para edades 10–13.
Usa `LIBRO.json` como fuente editorial bilingüe: 12 páginas, 3 capítulos, preguntas por página y vocabulario.
Las imágenes PNG no contienen narración; inserta el texto desde los campos ES/EN.

1. Inspecciona el contrato real `packages/contracts/src/story.ts` antes de adaptar los campos. No asumas que este JSON ya cumple el esquema.
2. Mantén las mismas nueve imágenes para ambos idiomas: hoja de personajes, portada y siete escenas. Las páginas sin imagen conservan su espacio de lectura.
3. Respeta la narración en primera persona de Isa y el orden de las páginas. No conviertas el desacuerdo en culpa unilateral ni acortes la disculpa a una solución instantánea.
4. Valida rutas, existencia y dimensiones 1536×1024, paginación, alternancia ES/EN, preguntas y render de la app.
5. Muestra al usuario una vista previa de lectura antes de publicar.

La carpeta incluye los PDF para lectura, dos vistas HTML y textos originales editables. El PDF tiene portada y 12 páginas de narración.
